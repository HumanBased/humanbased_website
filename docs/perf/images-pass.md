## Lightened images

Brightened in the file itself (sharp modulate plus a gamma lift, and a navy screen tint on Responsible Platforms and Organizational Enablement so shadows stay on palette) and with a lighter CSS wash:

- Responsible Platforms and Organizational Enablement (About grid): new `.ed-card-media--lit` in components/editorial.css (full image opacity, bottom wash 0.85 down to 0.38).
- Expert Mission, 24/7 Automation, Cost Reduction and Uncompromising Quality (Process outcomes): new `.vc-lit` modifier on `.visual-card-img` (opacity 1, no dimming filter) and a bottom gradient reduced from solid to 40%.
- Participation Increased: image lifted and bottom gradient reduced to 35%.
- We Serve for Real Impact: image lifted; the desktop left-to-right text wash reduced from 100/85% to 95/55%. Text still sits on the darkest left part of that wash.
